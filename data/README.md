# 원본 데이터

2018, 2019, 2021~2025년의 원본 CSV 21개를 보관합니다. 2020년 자료는 없습니다.

- `ESFA_YYYY70.csv`: 평가 입력 70건
- `ESFA_YYYY70answerkey.csv`: 같은 평가 문제의 정답지
- `ESFA_YYYY_remain.csv`: 예시 후보

파일 내용과 이름은 유지하고 루트에서 이 폴더로 옮겼습니다.
실험의 `data_dir: "."` 및 기존 manifest 경로는 그대로 사용합니다.
실험 로더는 하위 폴더를 검색하므로 실행 명령은 바뀌지 않습니다.
동일한 원본 CSV를 다른 하위 폴더에 복사하면 중복 데이터 오류가 발생할 수 있습니다.
