# 원본 데이터

2018, 2019, 2021~2025년의 원본 CSV 21개를 보관합니다. 2020년 자료는 없습니다.

- `ESFA_YYYY70.csv`: 평가 입력 70건
- `ESFA_YYYY70answerkey.csv`: 같은 평가 문제의 정답지
- `ESFA_YYYY_remain.csv`: 예시 후보

파일 내용과 이름은 유지하고 루트에서 이 폴더로 옮겼습니다.
실험의 `data_dir: "."` 및 기존 manifest 경로는 그대로 사용합니다.
실험 로더는 하위 폴더를 검색하므로 실행 명령은 바뀌지 않습니다.
동일한 원본 CSV를 다른 하위 폴더에 복사하면 중복 데이터 오류가 발생할 수 있습니다.

## 2026년 최종 평가 후보 자료

사용자가 제공한 `ESFA_202686.csv`와 `ESFA_202686answerkey.csv`를 원본 그대로 추가했습니다.
입력·정답지 각각 86개 고유 ID이며 입력의 모든 열이 정답지와 일치합니다.
정답은 Yes 64건 / No 22건, 목적은 Enforcement 46건 / Risk assessment 40건입니다.
입력 파일에는 EFSA 정답 열이 없으며 정답지에는 출처와 코멘트 열이 있습니다.
원문 출처의 적합성과 정답의 타당성을 독립 검증한 상태는 아닙니다.

기존 data 폴더의 2018·2019·2021~2025년 평가·정답·예시 후보와
5개 모델 입력 필드(substance, purpose, commodity, JMPR, EU)를 비교했습니다.
연속 공백을 정규화하면 `2026-14-01`, `2026-22-01`이 기존 입력과 겹칩니다.
86건 내부의 동일 기준 중복 입력은 없습니다. 원본에서 중복을 제거하지 않았습니다.
따라서 86건 전체를 완전히 새로운 입력으로 기술하지 말고, 평가 전 중복 처리 기준을 고정해야 합니다.

2026년 86건 전용 파일 형식을 로더에 추가했습니다. 기존 70건 검증은 유지합니다.
파일명을 70으로 바꾸거나 기존 데이터를 덮어쓰지 마세요.
평가 실행 방법과 정답 분리는 `docs/RUN_E6_FINAL_2026.md`를 참고하세요.
