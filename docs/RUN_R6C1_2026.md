# R6C1의 2026년 86문제 평가

## P0 추가 비교 평가

P0 계획도 `results/p0-eval-2026/plan.json`에 준비했다. 기존 R6C1과 문제·정답·모델 설정·반복 수·중복 제외 집합이 동일한지 검증한다. P0는 원래 탐색 계획의 `p0`이며 R6C1을 다시 호출하지 않는다.

```powershell
python -m residue_experiment.eval_2026 run --output results/p0-eval-2026 --mode live --max-calls 258
```

추가 258회. 결과는 `results/p0-eval-2026/live/summary.json`, `test_metrics.csv`, `test_predictions.csv`, `error_frequency.csv`에 저장한다. R6C1 결과와 같은 형식으로 전체·유형별·중복 제외 성능을 비교할 수 있다. 서로 다른 시점의 실행이라는 점은 비교 시 명시한다.

P0 준비 재현:

```powershell
python -m residue_experiment.eval_2026 prepare --condition P0 --output results/p0-eval-2026
```

## R6C1 평가

계획 준비 완료. R6C1만 86문제 × 3회 = 258회 평가한다. P0나 다른 후보는 호출하지 않고 지침을 수정하지 않는다. 기존 모델·예측 토큰 설정 등을 상속한다.

```powershell
python -m residue_experiment.eval_2026 run --mode live --max-calls 258
```

계획 준비 재현(유료 호출 없음):

```powershell
python -m residue_experiment.eval_2026 prepare
```

원본 CSV를 수정하지 않고 `results/r6c1-eval-2026/plan.json`에 입력·정답·지침을 고정한다. 원본 경로와 파일 해시도 기록한다. 실행은 고정 계획만 사용하므로 이후 원본 CSV 변화가 실행에 섞이지 않는다. 새로운 파일을 사용하려면 별도 output에 새 계획을 준비한다.

모델 입력은 substance, purpose, commodity, JMPR, EU 다섯 필드와 빈 examples뿐이다. 정답·해설·출처 메타데이터는 보내지 않는다. 반복마다 서로 다른 호출 키로 새 응답을 받고, 같은 반복을 재개할 때만 정상 완료 응답을 재사용한다.

10문제마다 진행 상황을 출력하고, 매 반복 완료 후 예측·지표를 저장한다. 전체 86개 성능과 기존 입력 중복 2개(2026-22-01, 2026-14-01)를 제외한 84개 성능을 함께 산출한다. 두 집합 각각 단속용·위험평가용 지표를 제공한다. 입력 중복 판정은 다섯 입력 필드의 줄바꿈·공백을 정규화한 비교이며 의미적 신규성을 보장하지 않는다.

결과 폴더: `results/r6c1-eval-2026/live/`

- `summary.json`: 전체 반복 완료 후 평균 정확도·Macro-F1·오류 방향별 합계
- `test_metrics.csv`: 집합·유형·반복별 지표
- `test_predictions.csv`: 현재까지 완료된 반복의 예측
- `repeat-01_predictions.csv` 등: 반복별 예측
- `error_frequency.csv`: 문제별 3회 오답 횟수
- `calls/`: 요청·응답 및 중단 기록

정상 완료 응답은 같은 명령 재실행 시 재사용한다. 빈 응답과 오류는 임의로 라벨로 바꾸거나 자동 재시도하지 않는다. 연결 오류의 복구는 실행이 종료된 후 실패 호출 ID를 확인하고 `repair-connection --mode live --call-id <64자리 ID>`를 사용한다. 빈 응답은 `repair-empty --mode live`로 보관할 수 있다. 보관한 호출도 예산에 포함되므로 실패 후 재시도가 필요하면 검토 후 누적 상한을 늘린다. 복구 명령은 API를 호출하지 않는다. 중복 실행 잠금을 임의로 삭제하지 않는다.

이 자료를 보고 프롬프트를 수정하기 전의 고정 지침 평가로 기록한다. 3회는 같은 86문제의 반복이며 독립적인 258문제가 아니다.
