# 위험평가용 정의 구분 개선: 반복 후보 생성·검증·선택

시작 지침은 R6C1이다. `risk_development/analysis/optimizer_10_proposal.json`의 개발 사례 10개를 고정하여, 최대 5라운드 동안 매번 후보 3개를 생성한다. 2라운드 연속 미개선, 10개에서 현재 오답이 없어짐, 최대 라운드 도달 시 종료한다. 호출 한도·오류 발생 시 중단 후 정상 완료된 응답을 재사용하여 재개할 수 있다.

## 라운드 구성

1. 현재 지침으로 위험평가용 개발 147개 및 단속용 누적 사례 41개를 평가한다. 정확히 같은 모델·설정·지침·입력의 유효 응답은 재사용한다.
2. 147개 중 고정된 10개의 정답과 현재 예측만 수정용 LLM에 제공한다. 첫 구성은 오답 2개·정답 8개이며, 이후 현재 예측에 따라 오류 상태를 갱신한다. 직전 라운드의 후보 지침과 해당 10개에서 교정·악화한 ID도 제공한다. 선택 자료의 점수·정답·예측은 제공하지 않는다.
3. 분석 1회, 후보 3개 생성 1회. 최소 추가·적용 한계 명시·재작성 후보를 요청한다.
4. 각 후보를 개발 위험평가용 147개, 단속용 누적 41개, 고정 선택 자료 140개에서 평가한다.
5. 개발 자료에서 목표 오답 하나 이상 교정, 위험평가용 정답 수 비감소, 단속용 누적 정답 수 비감소를 만족해야 채택 대상이다.
6. 채택 대상 중 선택 자료의 위험평가용 정확도가 현재 지침보다 높고 단속용 정확도가 낮아지지 않는 후보만 남긴다. 전체 정확도 → 전체 Macro-F1 → 짧은 지침 → 후보 생성 순으로 동점을 처리한다. 없으면 현재 지침을 유지한다.

첫 10개가 해결되면 새로운 오답을 자동 선정하지 않고 종료한다. 다음 오류 유형은 별도 검토한다. 새 50문제나 누적 목록을 매 라운드 추가하는 기존 v2와 달리, 이번 실험은 고정 10개와 고정 검증 집합으로 반복한다.

## 실행

준비 완료. 준비 명령은 유료 호출이 없다.

```powershell
python -m residue_experiment.risk_search prepare
```

전체 실행:

```powershell
python -m residue_experiment.risk_search run --mode live --max-calls 5258
```

1라운드만 먼저 실행하려면:

```powershell
python -m residue_experiment.risk_search run --mode live --through-round 1 --max-calls 986
```

이후 전체 실행 명령으로 재개하면 완료된 라운드와 정상 응답을 재사용한다. 한도는 이 실험 폴더의 누적 호출 수이며 추가 허용량이 아니다. 중복 실행하지 않는다.

초기 R6C1의 328건(147+41+140)은 모두 정확히 일치하는 기존 응답이 있음을 검증했다. 따라서 초기 평가의 새 호출은 0회이다. 라운드당 최대 2 + 3×328 = 986회, 5라운드 최대 4,930회 신규 호출이 예상된다. 계획의 5,258회는 초기 328건까지 포함한 보수적 상한이다. 동일 후보 캐시, 목표 해결 또는 조기 종료 시 더 적게 사용한다. 분석·생성 토큰 비용은 문제 판정 호출과 다르다.

모델과 호출 설정은 기존 R6C1 연장 실험에서 상속한다. 유료 실행은 위 live 명령에서만 발생한다. 실패·미완료·빈 응답을 자동으로 재시도하거나 임의로 라벨로 바꾸지 않는다.

## 결과

`results/r6c1-risk-search/live/round-NN/`에 현재 예측, 수정용 입력, 분석·후보, 각 후보의 개발·선택 예측, `selection.json`을 저장한다. 종료 시 `live/final_prompt.json`을 저장한다. 2023~2025년 테스트는 이 명령에서 실행하지 않는다.

선택 자료는 이미 반복 사용한 자료이며 독립적인 최종 평가가 아니다. 개발 성능은 지침 생성에 사용한 사례를 포함한다. 원문 정보 부족·정답 근거 불확실 문제를 억지로 맞추는 규칙, 물질별 정답 목록은 생성 요청에서 금지한다. 단속용 정확도 비감소는 신규 오답 0개를 의미하지 않으므로 교정·악화 ID도 확인한다.
