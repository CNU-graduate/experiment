# 잔류정의 검토 웹사이트

JMPR·EU 잔류정의 원문과 모델의 비교 결과를 확인하고 전문가가 최종 Yes/No 판정을 기록하는 로컬 웹사이트입니다.
이 디렉터리만 새로 추가하며 저장소의 기존 실험 코드, CSV, 설정 파일은 변경하지 않습니다.

## 실행

Python 3.11 이상이 필요합니다. 저장소 루트에서 실행하세요.

```powershell
python -m pip install -r website/requirements.txt
python website/server.py
```

브라우저에서 <http://127.0.0.1:8765>를 엽니다. 종료는 Ctrl+C입니다.
`website/start.ps1`로도 실행할 수 있습니다. 포트를 바꾸려면 `--port 8766`을 추가하세요.

별도의 프런트엔드 빌드는 필요하지 않습니다. HTML/CSS/JavaScript와 Python 표준 라이브러리 서버를 사용합니다.

## 사용 흐름

1. 검토 목록에서 농약명, 연도, 목적, 작업 상태로 사례를 찾습니다.
2. 목적과 적용 품목을 확인하고 JMPR·EU 원문을 나란히 검토합니다.
3. 연결된 모델의 비교 실행 결과에서 Yes/No 예측, 판정 근거 및 원문 인용을 확인합니다.
4. 전문가 판정, 이름, 검토 의견을 작성하고 임시 저장·보류·확정합니다.

최종 확정에는 Yes/No 판정, 검토자 이름, 원문 확인이 필요합니다. 보류에는 사유가 필요합니다.
이전 판정은 검토 이력에서 확인하며, 목록의 CSV 내보내기로 현재 검토 결과를 내려받습니다.
모델 결과 재생성은 전문가 판정을 덮어쓰지 않습니다. 오래된 창에서 저장하면 revision 충돌을 감지합니다.

## 모델 연결

기본 실행에서는 API를 호출하지 않으며 **모델 미연결**로 표시합니다. 비교 실행 버튼은 비활성화되고 전문가 직접 검토·저장은 가능합니다.
미연결 상태를 임의의 Yes/No 예측으로 표시하지 않습니다. 기존 미리보기 분석 기록도 실제 예측으로 표시하지 않습니다.

실제 사용을 승인한 운영자는 기존 저장소 루트의 `.env` 또는 서버 환경변수에 아래 항목을 설정합니다.

```dotenv
OPENROUTER_API_KEY=발급받은_API_키
REVIEW_MODEL=사용할_정확한_OpenRouter_모델_ID
```

`REVIEW_MODEL`이 없으면 기존 `GEMINI_MODEL` 값을 사용합니다. 키와 모델 설정을 마친 뒤 실행합니다.

```powershell
python website/server.py --live
```

사용자가 비교 실행을 눌렀을 때만 OpenRouter에 원문을 전송합니다. 키는 서버에서만 관리합니다.
JSON 응답을 지원하는 모델이 필요하며, 실제 API 호출에는 비용이 발생합니다. 자동 재시도는 하지 않습니다.
API 모델 가용성, 응답 품질, 비용은 개발 과정에서 유료 호출로 검증하지 않았습니다.
참고: [OpenRouter 공식 API 문서](https://openrouter.ai/docs/api_reference/overview).

전문가 화면에는 모델·예시 전략 선택을 노출하지 않습니다. 현재 웹 요청은 서버 기본 경로 E0를 사용합니다.
최적 모델이 이미 학습·선정되었다는 뜻은 아니며, 향후 선정한 모델을 서버 설정으로 연결할 수 있습니다.
내부 E1–E5 경로는 기존 `residue_experiment.selection.Selector`를 재사용하며 예시가 필요한 과거 연도에 없으면 오류를 반환합니다.
분석에는 모델, 입력, 예시, 프롬프트 버전과 해시, 사용량, 실행 시간 등이 저장됩니다.
인용문은 원문에 실제 존재하는 경우에만 강조할 수 있으며, 의미적 타당성은 전문가가 판단합니다.

## 데이터와 저장

- 저장소 루트의 `ESFA_*70.csv`를 읽어 현재 490개 사례를 가져옵니다. 2020년 원본 자료는 없습니다.
- 정답 `EFSA` 및 `efsa_comments`는 판정 대상 입력에서 제외합니다.
- 출처 링크는 원본 CSV에 기재된 메타데이터입니다.
- 사용자 직접 입력 사례를 추가할 수 있습니다.
- 판정과 분석 기록은 `website/data/reviews.sqlite`에 저장됩니다.
- 재실행 시 미등록 사례만 추가하며 기존 기록은 덮어쓰지 않습니다.
- 서버 종료 후 SQLite 파일을 복사하면 기록을 백업할 수 있습니다.
- DB, `.env`, 캐시, 로그는 Git에 포함하지 않습니다.

이 버전은 `127.0.0.1`에서 실행하는 로컬 작업용입니다. 검토자 이름은 직접 입력하며 계정 인증 기능은 없습니다.
웹사이트의 설명형 분석 프롬프트는 기존 실험의 Yes/No 전용 프롬프트와 다르므로 결과를 동일 실험 조건으로 합산하지 않습니다.

저장소 루트에서 실행합니다.

```powershell
python -m unittest discover -s website/tests -v
node --check website/static/app.js
```
